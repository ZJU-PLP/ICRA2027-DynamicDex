# Four-case tactile replays

Each HTML file is self-contained and contains the packet stream for its case. The viewer includes a play button and time slider and updates the recorded scene, four optical tactile panels, payload/CoM information, phase, and wrench values.

- com_bar.html
- basket.html
- drill.html
- pan.html

These are packet-level engineering/presentation replays. Tactile images are optical marker/deformation visualizations and are not calibrated force maps.
