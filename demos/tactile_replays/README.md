# Four-case tactile replays

The four HTML pages use the high-resolution MP4s and posters in `../../assets/replays_video/`. Keep that relative directory structure when copying the site for offline viewing.

- `com_bar.html`
- `basket.html`
- `drill.html`
- `pan.html`

Native video controls provide playback, seeking, and full screen without JavaScript, including in the Anonymous GitHub HTML sandbox. With JavaScript enabled, the expandable measurement panel adds phase navigation and recorded-sample inspection using the same video. The embedded measurement packets are unchanged. Sample-to-video times follow the timing used when each published video was encoded.

These are recorded engineering/presentation replays. Tactile marker and deformation displays visualize simulated contact forces and are not calibrated optical measurements.
