# Simulation demonstration files

These MP4 files are the four common-Home presentation recordings used to inspect the workcell, approach, grasp, payload motion, and hold phases:

com_bar.mp4
basket.mp4
drill.mp4
pan.mp4

Each recording has a compact JSON summary and a corresponding NPZ trajectory under data/simulation/trials/. These recordings are separate from the formal 1,395-trial controller evaluation in the paper.
